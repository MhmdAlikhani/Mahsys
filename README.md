# Mahsys
نرم افزار جامع حسابداری و مدیریت کسب و کار ماهسیس
   حاوی امکانات کامل مورد نیاز برای مدیریت جامع کسب و کار
   امکان استفاده رایگان سه ماهه تستی
   دارای امکان ارسال گزارش به سامانه مودیان
   حاوی همه زیر سیستم های لازم از جمله مدیریت مشتریان، مدیریت کالا، ثبت سفارشات مشتری، صدور فاکتور، وصول مطالبات، خرانه داری و مدیریت هوشمند چک های دریافتی و پرداختی، صدور اتومات اسناد انبار، صدور اتومات اسناد حسابداری، گزارشات متنوع عملکردی و ...
